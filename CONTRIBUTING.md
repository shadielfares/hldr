# Contributing to HLDR

Thank you for your interest in contributing to HLDR! Follow the steps below to set up the project for local development and debugging.

## Getting Started

1. **Fork the repository** to your own GitHub account.
2. **Clone your fork** to your local machine.

```sh
git clone https://github.com/your-username/hldr.git
cd hldr
```

3. **Install dependencies**:

```sh
npm install
```

4. **Start the watch mode**:

```sh
npm run watch
```

5. **Open the extension in a development host**:
   - Open `extension.ts` file.
   - Press `F5`.

This will open a new VS Code window with the extension loaded.

## Debugging

1. In the development host window, press `CTRL+SHIFT+P`.
2. Search for `Toggle Developer Tools` and select it.

This will open the developer tools where you can debug the extension.

Happy coding!
